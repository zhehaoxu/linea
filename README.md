# Linea · 数字电路画布

浏览器里的数字电路编辑器：拖放器件、连线、运行仿真，适合教学演示与快速验证逻辑电路。中文 / English 界面可随时切换。

技术栈：Vue 3.5 + TypeScript + Vite 8，无第三方 UI 依赖，画布为原生 SVG。

## 功能

- **器件**：输入开关、时钟；与、或、非、异或、与非、或非、同或门；指示灯、四位数码管；D 触发器
- **仿真**：运行 / 停止；开关与连线状态实时反馈；时钟频率 0.5 / 1 / 2 / 4 Hz；D 触发器按上升沿更新
- **编辑**：点击或拖拽添加器件、端口连线、框选多选、组合 / 解组、双击空白处添加文本标注
- **历史**：撤销 / 重做，最多 60 步
- **视图**：平移与缩放（30%–250%）、滚轮缩放、适应画布
- **模板**：半加器、全加器、2:1 多路选择器、SR 锁存器、D 触发器
- **导入 / 导出**：电路可导出为 JSON 文件，也可从文件导入（损坏文件会提示）
- **持久化**：电路自动保存到 localStorage，刷新后继续编辑
- **上下文菜单**：组合、解组、复制、剪切、粘贴、创建副本、删除

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 选择工具 / 抓手工具 | `V` / `H` |
| 临时平移 | 按住 `Space` 拖动 |
| 撤销 / 重做 | `⌘Z` / `⇧⌘Z`（`Ctrl` 同样，`⌘Y` 也可重做） |
| 全选 | `⌘A` |
| 复制 / 剪切 / 粘贴 / 创建副本 | `⌘C` / `⌘X` / `⌘V` / `⌘D` |
| 删除所选 | `Delete` 或 `Backspace` |
| 微调位置 | 方向键（按住 `Shift` 每次 8px） |
| 放大 / 缩小 / 适应画布 | `=` 或 `+` / `-` / `0` |
| 取消连线、清空选择、关闭菜单 | `Esc` |

双击空白处添加文本，双击文本节点重新编辑；右键画布、器件或连线可打开上下文菜单。

## 开发

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 类型检查 + 生产构建
npm run test       # 单元测试 + e2e
npm run test:unit  # Vitest
npm run test:e2e   # Playwright（使用本机 Chrome）
```

e2e 测试会自动在 `127.0.0.1:4173` 启动 dev server。

## 目录

```
src/circuit/      电路状态、仿真、持久化、器件规格与模板
src/components/   画布、顶部工具栏、左侧器件栏、器件节点、语言切换
tests/unit/       Vitest：状态历史、仿真、持久化
tests/e2e/        Playwright：编辑、分组、菜单、快捷键、仿真等冒烟用例
```

## 数据

- `linea.circuit.v1`：电路快照，格式为 `{ type: 'linea-circuit', version: 1, nodes, wires, groups }`
- `linea.locale.v1`：界面语言
